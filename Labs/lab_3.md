# Лабораторная работа №3. Управление конфигурациями и трекинг экспериментов

## Цель работы

Научиться:

1. выносить параметры эксперимента в структурированные конфиги;
2. версионировать данные и модели через DVC;
3. логировать метрики, гиперпараметры и артефакты экспериментов;

## Ход работы

### 1. Задача

Возьмите любую простую задачу, например дообучите классификатор (`cointegrated/rubert-tiny2`) на датасете токсичности [`AlexSham/Toxic_Russian_Comments`](https://huggingface.co/datasets/AlexSham/Toxic_Russian_Comments). 
Можете использовать не все данные, а небольшое подмножество. Смысл лабы не в получении наиболее качественной модели, а в настройке базовой инфраструктуры вокруг обучения.

### 2. Конфигурация экспериментов

Структурируйте параметры эксперимента в конфиги Hydra: `config/`, с отдельными группами хотя бы для:

- параметров модели;
- параметров обучения (learning rate, batch size, число эпох);
- путей к данным.

Запуск скрипта обучения должен позволять переопределять параметры через CLI без правки кода:

```bash
python train.py model.lr=1e-4 training.batch_size=32
```

### 3. Версионирование данных

Датасет грузится с HuggingFace. Версионируйте подмножество, с которым вы реально работаете: выгрузите выбранные train/val примеры в CSV или parquet (например, `data/train_subset.csv`, `data/val_subset.csv`), и уже эти файлы добавьте в DVC (`dvc add`). 

Remote можно назначить любой удобной папкой на вашей машине (отдельная папка вне репозитория, например `~/dvc_storage`) или, при наличии, на удалённом сервере. 

### 4. Трекинг экспериментов

Выберите удобный вам трекер экспериментов (MLflow, W&B, ClearML, какой-либо ещё) и залогируйте для каждого запуска:

- гиперпараметры (автоматически из конфига Hydra);
- метрики по эпохам (loss + минимум одна метрика качества);
- финальный чекпоинт модели как артефакт.

Проведите минимум 3 запуска с разными гиперпараметрами, чтобы в трекере было что сравнивать.

### 5. Воспроизводимость

Зафиксируйте `seed` везде, где это требуется (numpy, torch, python random). Будет плюсом README с описанием, как воспроизвести лучший из ваших трёх запусков.

## Что сдаётся

- Репозиторий с конфигами и скриптом обучения.
- DVC-трекинг (датасета, чекпойнтов модели, чего-либо ещё).
- UI трекера по выбору, в котором видно несколько запусков обучения.
- Будет плюсом, но не обязательно -- небольшой README с инструкцией по воспроизведению.

## Примерные вопросы
